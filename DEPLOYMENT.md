# Deployment Guide for AquaWash Laundry

## Fixing the Blank Screen Issue

The blank screen is likely because GitHub Pages is serving the wrong files. Follow these steps:

### Option 1: Automatic Deployment (Recommended)

1. **Push the code to GitHub** (if not already done):
   ```bash
   git add .
   git commit -m "Fix deployment configuration"
   git push origin main
   ```

2. **Enable GitHub Actions**:
   - Go to your repository on GitHub
   - Click on "Actions" tab
   - The workflow will automatically run when you push to main/master
   - Wait for it to complete (check the green checkmark)

3. **Configure GitHub Pages**:
   - Go to Settings → Pages
   - Under "Source", select "GitHub Actions"
   - Your site should now be live!

### Option 2: Manual Deployment

If you prefer manual deployment:

1. **Build the project**:
   ```bash
   npm run build
   ```

2. **Deploy the `dist` folder**:
   - Copy ALL contents from the `dist` folder
   - Push them to your `gh-pages` branch OR to the root of your main branch
   - Make sure `index.html` is in the root of the deployed folder

3. **Configure GitHub Pages**:
   - Go to Settings → Pages
   - Select the branch containing the `dist` files
   - Set the folder to `/` (root) or `/dist` depending on where you put the files

### Important Notes:

- ✅ Always deploy the **`dist`** folder contents, NOT the `src` folder
- ✅ The `dist` folder is generated by running `npm run build`
- ✅ Make sure your custom domain (www.aquawashlaundry.in) is set in the CNAME file
- ✅ The GitHub Actions workflow will automatically build and deploy on every push

### Troubleshooting:

1. **Still seeing blank screen?**
   - Open browser console (F12) and check for JavaScript errors
   - Verify that assets are loading (check Network tab)
   - Make sure the `dist` folder contents are in the root of your deployed branch

2. **Assets not loading?**
   - Check that paths in `index.html` are correct (should be `/assets/...`)
   - Verify GitHub Pages is serving from the correct directory

3. **Check the live site**:
   - Visit: https://www.aquawashlaundry.in
   - Open browser console to see any errors

### Quick Fix Command:

```bash
# Build and check
npm run build

# Verify dist folder exists and has files
ls -la dist/
```

The `dist` folder should contain:
- `index.html`
- `assets/` folder with CSS and JS files
